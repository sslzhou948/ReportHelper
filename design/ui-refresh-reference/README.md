# UI Refresh Reference

Design reference images copied from Codex temp attachments.

## Source of truth

This folder is the visual source of truth for the UI refresh. Other legacy design files in the repository, especially `healthhelper_design`, may be used only to understand existing page scope and functional intent. They must not be used to decide the new visual direction, component styling, spacing, color, or page hierarchy.

Do not generate production miniprogram code directly from these images. First extract design tokens and component rules, then apply them through WXML/WXSS and reusable miniprogram components while preserving existing page JS business logic.
