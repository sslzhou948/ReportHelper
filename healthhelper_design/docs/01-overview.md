## 1. 产品定位

**我的病例夹** 是一个面向慢性病（尤其是肿瘤术后康复）患者及其家属的**微信小程序**，定位为**电子病例夹 · 公益免费**。

核心价值主张：

> **把零散的纸质 / 拍照报告集中起来，看清健康指标的变化趋势，不错过下一次复查。**

不是医疗诊断工具，不替代医生，不做线上问诊。

---

## 2. 目标用户

### 主要用户：患者本人
- 年龄段：50-70 岁为主，覆盖到 40-80 岁
- 典型场景：乳腺癌 / 肺癌 / 结直肠癌等术后康复患者，需要长期定期复查
- 技术水平：会用微信、能拍照、能微信支付；不熟悉复杂表单和多层菜单
- 视力：可能需要老花镜，对小字号、低对比度敏感

### 次要用户：患者家属
- 子女代为管理父母的检查报告
- 帮老人录入数据、查看趋势、设置提醒

### 设计含义
- 字号最小 13px，关键信息 ≥ 16px
- 操作步骤要短，关键 CTA 要大、要醒目
- 文案口语化，避免医学术语堆砌（指标名要保留，但描述要白话）
- 中文优先，不使用英文 UI 标签

---

## 3. 核心功能模块

| # | 模块 | 一句话功能 |
|---|------|------------|
| 1 | 报告管理 | 拍照 / 相册上传，AI 识别并结构化为指标 |
| 2 | 指标追踪 | 把多次报告中的同一项指标串成趋势 |
| 3 | 复查计划 | 待办清单形式，提醒用户下次去医院 |
| 4 | 个人档案 | 病种、用药、主治医生等基础信息 |

---

## 4. 不做什么（明确范围）

- ❌ 不提供诊断结论，只展示数据
- ❌ 不联网医院 HIS 拉数据（所有数据由用户主动上传）
- ❌ 不做医患沟通 / 在线问诊
- ❌ 不做药品电商
- ❌ 不存储基因数据 / 病理影像原图（只存检查单 OCR 结果 + 缩略图）
- ❌ 不出 web 版 / APP 版（仅微信小程序）

公益项目，**完全免费**，无广告，无内购。

后端服务器与 OCR / AI 解读成本由公益资金承担。**[需确认：成本预算 + 公益主体]**

---

## 6. 设计基调

- **配色**：橄榄绿 `#5A7A5A` 主色 / 米色 `#EDEAE4` 背景 / 玫瑰红 `#C07060` 警示
- **字体**：PingFang SC（iOS 默认）+ HarmonyOS Sans（Android）
- **风格**：温暖、克制、不医疗冷感；圆角 14-22px，柔和阴影
- **emoji 使用**：仅在用户引导文案少量使用（如 👆），UI 主体不依赖 emoji

---

## 7. 关键非功能要求

| 项 | 要求 |
|----|------|
| 首屏可见时间 | ≤ 1.5s（4G 网络） |
| 报告上传到识别完成 | ≤ 15s（5 张照片以内） |
| 隐私 | 所有数据加密存储，仅用户本人 + 授权家属可见 |
| 离线 | 已查看过的数据可离线查看；上传需联网 |
| 兼容 | 微信 8.0 以上，iOS 12+ / Android 8+ |
